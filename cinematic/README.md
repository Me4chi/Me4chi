# ME4CHI — кинематографичный пиксельный портфолио-опыт

Исходники новой версии сайта. Сборка кладётся в `../journey/` и публикуется GitHub Pages как
`https://me4chi.github.io/Me4chi/journey/`. Текущий сайт (`../index.html`) **не тронут**: он остаётся
живой версией и одновременно служит упрощённым режимом («Classic»).

```bash
npm install
npm run dev       # локальная разработка
npm run check     # самопроверка: состояние сцены — чистая функция прогресса скролла
npm run build     # typecheck + сборка в ../journey
```

Статус: **вертикальный срез — Глава I «Awakening» полностью рабочая.** Главы II–V — раскадровка ниже,
в навигации помечены как «in production».

## 2. Арт-спецификация

| Параметр | Значение |
|---|---|
| Единица мира | 1 world px = 1 пиксель арта |
| Виртуальная высота кадра | 180 world px (landscape), 260 (portrait); ширина — по аспекту |
| Линия земли | y = 150 |
| Персонаж | 14×24 px, вид сбоку, собран из голова (7) + тело (11) + ноги (6) |
| Тайловый шаг | 8 px (каменная дорожка, ступени) |
| Палитра | Forest `#101D18`, Foliage `#203A2D`, Moss `#456B4C`, Jade `#739A75`, Parchment `#E6DDC7`, Lantern `#E8AD63`, Night `#10151C`, Mist `#A8BDB0` + киноварь тории `#9A3D2C`, камень `#6B6E66` |
| Свет | Источник — луна сверху слева; листва дизерится упорядоченной матрицей Байера 4×4 |
| Фильтрация | Только nearest-neighbour (`TextureSource.defaultOptions.scaleMode`), `image-rendering: pixelated` |
| Анимация | Шаг ходьбы — 1 кадр на 5 world px пройденного пути (без скольжения ног при скрабе); idle — порыв шарфа |

**Стратегия рендера (камера vs пиксели).** Зум непрерывный, текстуры nearest, позиции каждого слоя
снапятся к физическому пикселю экрана. Итог: движение плавное и без мерцания, а размер одного
world px на нецелом масштабе может отличаться максимум на 1 физический пиксель. Слои глубины
масштабируются как `1 + (zoom − 1)·depth` — это осознанный 2.5D-приём: дальние слои «ближе к
горизонту» и их пиксели при наезде растут медленнее.

**Цвет.** Всё нарисовано в нейтральном альбедо; освещение — мультипликативный tint по глубине
(`far` → `near`) из пресетов `void / moonlit / lanternlit`. Эмиссивные источники (окно фонаря,
светлячки, луна) на отдельном слое и не затемняются.

## 3. Архитектура

```
src/
  app/          App.tsx (UI), bootstrap.ts (связка движка), store.ts (Zustand)
  engine/       Renderer, CameraDirector, CinematicScrollDirector, ParticleSystem, AudioManager, pixel.ts
  animation/    types.ts (типизированные keyframes/каналы), lighting.ts (пресеты), keyframes/awakening.ts
  scenes/       awakening/AwakeningScene.ts + art.ts (процедурная пиксельная живопись слоёв)
  entities/     Character.ts
  components/   ChapterNav, ControlBar, StageOverlay, LoadingScreen, Epilogue
  data/         content.ts — весь реальный контент портфолио
tests/          director.check.ts
```

**Один цикл.** `gsap.ticker` → `lenis.raf` → `director.evaluate()` → `camera.frame()` →
`scene.update()` → `app.render()`. У Pixi собственный тикер выключен; React не участвует в кадре,
DOM пишется только при изменении (метка плана, прогресс-рейка).

**CinematicScrollDirector.** ScrollTrigger отдаёт прогресс 0…1. Директор переводит его в полное
состояние кадра: камера (x, y, zoom — зум интерполируется в лог-пространстве), каналы
(`darkness`, `lantern`, `fog`, `fireflies`, `characterX`), смешанные цвета света, поза и
направление персонажа. Состояние — **чистая функция прогресса**: обратный скролл, прыжок по
главам и перезагрузка посреди страницы всегда дают тот же кадр (`npm run check`). Каждая главa
задаёт свою длину в высотах экрана; директор собирает их в общий таймлайн.

**CameraDirector.** Кадр задаётся точкой фокуса в мировых координатах и зумом; для portrait —
отдельные переопределения (`portrait: { x, y, zoom }`). Добавляет медленный «ручной» дрейф
(отключается в reduced motion). Переводит кадр в трансформы слоёв с параллаксом и снапом.

**HTML-текст** (титр, карточка главы) — отдельный GSAP-таймлайн с метками
(`awakening.title` …) и stagger-ом, прокручивается тем же прогрессом (`tl.progress(p)`), поэтому
тоже полностью обратим. Текст остаётся настоящим, выделяемым HTML.

**Решения, отличающиеся от ТЗ:**
- **Howler.js не подключён**: записанных звуков пока нет, поэтому звук — синтез Web Audio (ветер,
  гул, сверчки), выключен по умолчанию. Переход на Howler — когда появятся файлы в `public/assets/audio`.
- **Спрайт-атласы**: весь арт процедурный и рисуется при загрузке в canvas (по одной текстуре на
  слой), поэтому атлас пока не нужен — `Texture` создаётся один раз, в кадре — ни одной аллокации.
- **Three.js не используется** — 2.5D-параллакса Pixi достаточно.

**Производительность и надёжность.** Монитор времени кадра: при ~1,5 с ниже ~40 fps разрешение
рендера снижается ступенями 2 → 1.5 → 1 → 0.75 и урезается число частиц. Пул светлячков на typed
arrays. Когда эпилог перекрывает экран, рендер останавливается. `webglcontextlost` → сообщение с
перезапуском; нет WebGL → сообщение и ссылка на Classic. Мобильные: меньше частиц, портретные
ракурсы, высота кадра 260 px.

**Доступность.** Skip intro, навигация по главам (клавиатура, Esc, фокус), переключатель
«Motion: calm» (без Lenis, без дрейфа камеры, светлячки неподвижны; уважает
`prefers-reduced-motion` и запоминается), звук выключен по умолчанию, текстовое описание сцены для
скринридеров, эпилог с полным контентом в обычном HTML, ссылка на Classic-версию.
